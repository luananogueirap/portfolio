# Portfólio — Luana Nogueira

Portfólio profissional de Luana Nogueira, desenvolvedora Backend e Full Stack em formação. A página apresenta sua formação, stack e os estudos de caso dos projetos **Toughts** e **Get A Pet**, incluindo os diagramas completos de arquitetura.

## Conteúdo

- apresentação profissional e formação;
- tecnologias de backend, frontend, dados e deploy;
- estudos de caso com funcionalidades, arquitetura e links para as aplicações;
- visualização ampliada dos diagramas;
- download dos arquivos editáveis do Excalidraw;
- currículo em PDF e contatos profissionais.
- player retrô interativo com equalizador, faixas fictícias e efeitos sonoros sutis.

## Tecnologias do portfólio

- HTML semântico;
- CSS responsivo com animações acessíveis;
- JavaScript;
- HTML, CSS e JavaScript puros, sem etapa de build.

## Abrir localmente

Abra o arquivo `index.html` com dois cliques. A página funciona diretamente no navegador.

Se preferir executar por um servidor local, entre nesta pasta pelo terminal e use:

```powershell
python -m http.server 5500
```

Depois, abra `http://localhost:5500`.

## Publicar na Vercel

Importe o repositório na Vercel e escolha **Other** como Framework Preset. Deixe os campos de comando de build e diretório de saída vazios. A Vercel publicará o `index.html` diretamente, sem instalar dependências e sem variáveis de ambiente.
